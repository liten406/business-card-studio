# Публикация полного редактора на Cloudflare Pages

В этой папке лежит полный редактор `index.html`. Это не экспортированная клиентская карточка: посетитель может создавать проекты, редактировать разделы, добавлять фотографии, истории, услуги и новости, а затем выгружать самостоятельную страницу для клиента.

## Быстрый запуск

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com/) и войдите в свой аккаунт.
2. Перейдите в `Workers & Pages` → `Create application` → `Pages` → `Upload assets`.
3. Введите имя проекта, например `business-card-studio`.
4. Перетащите в поле загрузки содержимое этой папки: минимум `index.html` и `_headers`. Можно загрузить архив `cloudflare-pages.zip` из папки `outputs`.
5. Нажмите `Deploy site`. Cloudflare выдаст адрес вида `https://business-card-studio.pages.dev`.
6. В `Custom domains` можно подключить свой домен.

Повторная публикация новой версии делается тем же способом. При загрузке заменяйте `index.html` и `_headers`.

## Что будет работать после публикации

- Полный редактор и все разделы карточки.
- Загрузка контента, истории, автоматическое воспроизведение слайдов, экспорт клиентской страницы, импорт и экспорт JSON.
- Несколько проектов в одном браузере.
- Работа без сервера приложений: после первой загрузки редактор не зависит от локального `127.0.0.1`.

## Важное ограничение текущей версии

Проекты, тексты и медиа сохраняются в IndexedDB браузера. Поэтому данные пользователя доступны в том же браузере и на том же устройстве, но не синхронизируются с другим компьютером и не видны другим пользователям сайта. Для резервного хранения используйте `Экспорт проекта` (JSON).

Если нужен общий кабинет агентства с пользователями, ролями и проектами, которыми можно пользоваться на разных устройствах, нужен следующий этап: авторизация и облачное хранилище. Для Cloudflare это обычно Workers + D1 для данных + R2 для медиа. Это уже серверная часть, которой в этом статическом прототипе пока нет.

`Карточка-*.html`, скачиваемая кнопкой «Скачать для клиента», — это отдельная витрина одного клиента. В ней специально нет редактора и списка проектов. Её загружают в отдельную папку или на отдельный домен как `index.html`.

Стартовые изображения демонстрационного проекта загружаются с Unsplash. Добавленные пользователем изображения встраиваются в проект и выгрузки.
