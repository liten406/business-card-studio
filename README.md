# Студия карточек бизнеса

Временный хостинг полного редактора карточек.

## Как запустить на GitHub Pages

1. Загрузите файл `index.html` из архива `cloudflare-pages.zip` в корень этого репозитория (замените текущий заглушечный файл).
2. Перейдите в **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   **https://liten406.github.io/business-card-studio/**

## Что работает

Полный редактор карточек: создание проектов, фото, истории, услуги, отзывы, экспорт клиентской страницы и т.д.

Данные хранятся в браузере (IndexedDB).

Для Cloudflare Pages используйте файлы из того же архива.
